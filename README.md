# LouvorSync - Escala e Repertório de Louvor

Sistema moderno de gestão de escalas de músicos, repertório, cifras e avisos de ensaio para equipe de louvor.

## 🚀 Funcionalidades
- **Líder da Equipe:** Painel macro do mês, gestão de escalas detalhadas por culto, banco de integrantes e distribuição de carga/frequência.
- **Ministro(a):** Montagem de repertório, indicação de tom original e alterado, links do YouTube e integração de cifras.
- **Músicos & Integrantes:** Visualização individual personalizada, confirmação de presença (Ciente), cifras com transposição de tom e visualização em 2 colunas para mobile.
- **Exportação & WhatsApp:** Mensagens automáticas formatadas prontas para envio com dados de ensaio e escala.
- **Tema Claro & Escuro:** Design limpo e adaptativo.

## 🛠️ Tecnologias
- React 18 + Vite
- Tailwind CSS
- Lucide React

## 📦 Como rodar localmente
```bash
npm install
npm run dev
```
